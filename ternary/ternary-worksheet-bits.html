1. Your two tables, as layers

Each table is a threes layer and a ones layer. Every cell is 3 × (threes digit) + 1 × (ones digit).

2. Each layer stored as two bit layers

A computer can't hold −1, 0, +1 in one bit, so every ternary layer becomes two bit layers: a plus layer with a 1 wherever the digit is +1, and a minus layer with a 1 wherever it is −1. A 0 is simply 0 in both.

What it cost

Each AND and count handles up to 64 positions at once on a normal computer word, so for real model sizes (rows of 256 or more numbers) the bit way does far more work per step than this tiny 2 × 2 example shows. Whether that beats a GPU's built-in 8-bit multiply is still untested.
